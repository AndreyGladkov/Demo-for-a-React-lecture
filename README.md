# mini-hh

Уменьшенная копия hh.ru к лекции «Большой проект изнутри». BFF на Express собирает стейт страницы, сервер рендерит React в HTML, клиент гидрирует его с тем же Redux-стором. В приложении воспроизводятся три бага, которые в своё время дошли до прода hh.ru.

```sh
npm install
npm run dev        # http://localhost:4040
npm test
npm run test:2fa-bug  # тот же тест на версии с багом — красный
```

Всё переключается в «панели лектора» в правом нижнем углу: тип пользователя, сайт, язык сайта, язык браузера, эксперименты, StrictMode и исправление каждого бага.

| Сценарий | Настройки | Что смотреть |
|---|---|---|
| Вход с подтверждением по коду | Работодатель, эксперимент `employer_login_2fa` | После неверного кода форма теряет логин: новый код не отправляется, верный 4242 тоже не уходит на проверку |
| Создание вакансии | Работодатель, hh.kz, локаль браузера kk-KZ | Ошибка гидрации в консоли: «30 августа, пятница» против «30 тамыз, жұма» |
| Создание вакансии из готового шаблона | Работодатель, `?fromPreparedTemplateId=3` | Страница перезагружается по кругу, растёт счётчик запросов в BFF |
| Поиск вакансий | Любые | DevTools → Performance monitor и Memory → Detached elements после «Открыть и закрыть ×10» |
| RTK Query на главной | Любые | «Показать счётчик»: счётчик сам грузит данные и работает без списка. «Показать список»: второго запроса нет, в Network один `vacancies`. Скрыть и показать в течение минуты — запроса нет, данные из кеша |
